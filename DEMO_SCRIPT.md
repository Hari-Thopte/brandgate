# 90-second judge demo

1. Open the landing page and choose **Try the demo brand**.
2. Keep the Reviewer role selected, then choose **Risky · planted mistakes**.
3. Select **Analyze ad**. The API reports the current pipeline stage while deterministic checks run. If the API is unavailable, retry or use the clearly labeled saved sample result.
4. Select a source chip to see the matched text, source reference, and grounding check.
5. Accept a finding, edit one suggestion, and dismiss one with a reason. Decisions remain human-controlled.
6. Add a reviewer comment, resolve the remaining findings, then approve the item.
7. Open the audit timeline and inspect the recorded actions; export Markdown or JSON if useful.
8. Visit **Brand Hub** and **AI & Privacy**.

Offline review uses the committed fixture in this browser session. It does not run the pipeline or persist to a database. Production checks require a deployment URL.
