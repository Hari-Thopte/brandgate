# Submission placeholders

The updated Round 2 project PDF intentionally contains these visible placeholders:

- `[[PUBLIC_APP_URL]]` — replace after deploying the frontend and API, then completing a production smoke test.
- `[[GITHUB_REPOSITORY_URL]]` — replace after creating the GitHub repository and pushing the source ZIP contents.

Neither URL is available in the current workspace. Do not submit these placeholders as live links. The current app runs locally using the included instructions; local preview URLs are not public project links.
