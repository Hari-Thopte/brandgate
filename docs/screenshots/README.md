# Screenshot and contrast evidence

The current UI is a warm Copy Desk design with persisted Light/Dark themes. Local captures are written to `qa/` at 1220, 1440, 1024, 768, and 390 pixels. The final set includes both themes for Landing, Start, Workspace, Audit, Brand Hub, Privacy, Queue, and the not-found route.

The automated contrast report checks visible text color against its nearest composited background for Landing, Start, Workspace, and Audit in both themes. It reports font availability for Instrument Sans and Fraunces. It is a local visual check and does not replace a public deployment review.
