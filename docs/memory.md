# Memory

## Decisions
- Build in a separate `BrandComplianceCopilot/` folder because the workspace's existing project is Satark and has unrelated product decisions.
- Use an in-memory local repository as the simplest judge-ready fallback; Supabase DDL and seed data are included for subsequent provisioning.
- Keep model review optional; deterministic rules and the stored sample findings are the demo path.
- Ledger match runs before LLM review.
- Use a small Vite ES-module frontend for the local demo to keep its setup dependency-light; this differs from the specified Next.js/TypeScript production stack and needs migration before treating this as the hosted app.
- Local demo requires two PowerShell windows: FastAPI in `backend/` and Vite in `frontend/`. README includes exact commands and the API health URL to avoid running either command from the wrong folder.
- The local “Failed to fetch” incident was caused by both development servers being stopped. The browser showed `ERR_CONNECTION_REFUSED` for `/health`; starting FastAPI from `backend/` restored API analysis. No hosted frontend/API URL exists in project configuration, so Vercel URL, mixed-content and production CORS checks are unverified.
- API calls have a 20-second timeout and one retry. When the API remains unreachable for the exact planted sample, the reviewer may choose a bundled fixture. Offline mode is labeled as saved-result review, not pipeline analysis; its decisions and audit history are local to that browser session.
- Review UX upgrade decisions: score is a transparent heuristic (100 minus weighted open findings: High 15, Medium 7, Low 3), not an accuracy measure. Revised/Diff are previews only and never mutate original ad copy. Seed data has no ledger expiry/source metadata, so the UI does not invent it.
- Preserve the original Round 2 scope: no dashboard queue or upload flow, and no expanded motion beyond the approved design animations. The attached upgrade list conflicts with the PRD queue exclusion and requests expiry dates absent from seed data; those items remain deferred.
