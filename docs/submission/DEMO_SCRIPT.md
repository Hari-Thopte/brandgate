# Judge demo script

## 90-second live path

1. Open the public URL (or local URL for a local demo) and choose **Try the demo brand**. Point out that the role switcher changes demo context and no account is required.
2. Select Reviewer and **Risky · planted mistakes**. Click **Analyze ad**; observe stage progress.
3. In the workspace, inspect the six highlighted, sourced findings and point to the deterministic/sample-result label. Accept one; dismiss another with a reason.
4. Resolve the remaining open findings, add a short reviewer comment, then click **Approve item** and confirm. Show the Approved stepper and audit timeline.
5. Open Brand Hub → Guidelines, Terms, Facts Ledger, then AI & Privacy.

## 60-second recording backup

Record the same path at a readable desktop size. Pause on the pipeline progress, a highlighted finding with its source, the dismissal reason, the approval confirmation, and audit entries. State that the current demo uses deterministic checks and a saved sample fallback; do not describe unavailable model, database, or deployment services as live.

## Before presenting

Use an actual reachable deployment URL and verify it with `DEPLOY.md`. If the API is unavailable, choose the explicitly labelled saved demo result. No production URL is currently recorded in this project.
